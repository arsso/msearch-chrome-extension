msearch

Arc-style command palette for Chrome. One box for open tabs, history, bookmarks, web search and browser commands.

Source on GitHub Privacy policy

Shortcut

⌘ ⇧ K on macOS, Ctrl Shift K on Windows and Linux. Change it at chrome://extensions/shortcuts.

What you can do

  • Empty box shows your most recent tabs. Type to search tabs, bookmarks, history, suggestions and commands.
  • Type a URL or domain to get a Go to row.
  • ↑ ↓ to move, ↵ to open, ⌘↵ to open in a new tab, Esc to close.
  • Commands: new tab, close tab, reopen closed tab, copy URL, pin, mute, reload, duplicate, incognito window, bookmark page.

Install from source

  1. Clone the repository and open chrome://extensions.
  2. Enable Developer mode, click Load unpacked and pick the src/ folder.
  3. Reload any tabs that were already open.

Settings

Right-click the extension icon and choose Options to pick the search engine (Google, DuckDuckGo, Bing) and turn search suggestions on or off.

Open source. No tracking, no analytics. Privacy policy.
